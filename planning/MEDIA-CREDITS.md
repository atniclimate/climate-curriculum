# Media, Data, and Library Credits

Every photo, video, dataset, font, and third-party code library used on the
site gets a row before it ships. Keep in step with the IMAGES registry in the
page script.

Rights rule: photos not taken by ATNI staff need confirmed rights before wider
sharing. Public Domain claims are checked on the item's own page (for example,
the license line on a USFWS media item), not assumed from the site.
